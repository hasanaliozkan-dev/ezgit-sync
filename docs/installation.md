# Installation

## Stable release

To install ezgit-sync, run this command in your terminal:

```sh
uv add ezgit-sync
```

Or if you prefer to use `pip`:

```sh
pip install ezgit-sync
```

## From source

The source files for auto_git can be downloaded from the [Github repo](https://github.com/hasanaliozkan-dev/ezgit-sync).


You can either clone the public repository:

```sh
git clone https://github.com/hasanaliozkan-dev/ezgit-sync
```

Or download the [tarball](https://github.com/hasanaliozkan-dev/ezgit-sync/tarball/main):

```sh
curl -OJL https://github.com/hasanaliozkan-dev/ezgit-sync/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd ezgit-sync
uv sync
```
